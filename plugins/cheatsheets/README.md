# cheatsheets

Offline cheat sheets for Wilfred: `cheat` lists topics (git, vim, tmux),
`cheat git` lists entries, `cheat git rebase` filters. Enter copies the
command.

To extend: add rows to the `kGit`/`kVim`/`kTmux` tables (or a new
`CheatTopic`) in `cheatsheets.c` and bump `version` in `plugin.yml`.

## Build

Same single-file recipe as [dice](../dice/README.md).
