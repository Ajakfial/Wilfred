# What Wilfred stores on your computer

Wilfred is a local desktop application. Its settings, clipboard history,
reminders, quick notes, snippets and search index live under a Wilfred
folder in your user profile (%LOCALAPPDATA%\Wilfred). Wilfred does not
send usage data or telemetry anywhere.

The installer adds the Wilfred program folder to your user PATH so the
wilfred command works in terminals. Clearing data or removing Wilfred
entirely is available from the command line (see wilfred.default.yml and
README.md), and uninstalling from Add/Remove Programs removes the
program files and shortcuts but deliberately leaves your notes, history
and index in place.
