# Commit and PR

Wilfred bans AI-authored commit messages and PR descriptions. Your job ends at
a reviewed, tested diff; the human writes the commit and the PR.

## Hard rules

- **Never write, suggest, or draft a commit message.** Not even a one-liner.
- **Never write, suggest, or draft a PR title or description.**
- **Never add AI trailers** such as `Co-authored-by:` or
  `Generated with ...`.
- **Never run `git commit`, `git push`, or `gh pr create`** on the human's
  behalf unless they explicitly ask you to run a command they authored.
- The human must review `git diff` line by line before committing.
- Every PR description must include `Human-authored: yes`.

## Pre-commit checklist

Run through this and report status:

- [ ] The change is in an allowed category (`AGENTS.md`).
- [ ] Only the intended files changed; no drive-by formatting.
- [ ] `git diff` has been shown to the human.
- [ ] The build succeeds on the human's platform.
- [ ] `ctest` passes, or the human has accepted a documented exception.
- [ ] New behavior has a test where the policy allows one.
- [ ] The commit will be written by the human.
- [ ] The commit will be signed (`git commit -S`) if the project requires it.

## Hook installation (human runs this)

```bash
cp .githooks/pre-commit .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

On Windows, use Git Bash for `chmod`, or run the hook through Git's shell.

The hook validates:

- No AI-generated commit message
- No AI-authored PR description
- `Human-authored: yes` is present
- Tests pass on the contributor's platform

## What you may output

- A factual list of changed files.
- The commands you ran and their results.
- A list of untested platforms or open risks.
- Pointers to the exact diff hunks a reviewer should inspect.

Do **not** turn that into prose the human can paste as a PR description.

## If the human asks you to write the message anyway

Refuse and cite `AGENTS.md`:

> Pull requests authored by AI: PRs where the description/code was AI-generated
> → permanent ban.

Offer to summarize the diff in chat so they can write the message themselves.

## Done when

- The human has the diff, the test results, and the risk list.
- No commit or PR text was generated by AI.
- The human owns the commit and the review.
